# Changelog

All notable changes to TeapotLang are documented here.

TeapotLang is currently in alpha, so releases may contain breaking changes as the language and compiler design evolves.

## [Unreleased]

Changes on the development branch that have not yet been included in a release.

## [0.5.4-alpha]

- Added a browser-based TeapotLang compiler experience.
- Added the JavaScript compiler bridge and Python web integration used by the web interface.
- Redesigned and expanded the project website.
- Updated the README, development documentation, and language reference.
- Added automated GitHub Pages deployment and Dependabot configuration.
- Added `robots.txt` and `sitemap.xml` for improved search-engine discoverability.
- Made minor compiler entry-point and documentation refinements.

## [0.5.3-alpha]

- Added the TeapotLang project website.

## [0.5.2-alpha]

- Updated stale documentation.

## [0.5.1-alpha]

- Simplified the semantic analyser's scope handling.
- Removed an unused test fixture.

## [0.5.0-alpha]

- Introduced the first-pass semantic analyser and symbol-table infrastructure.
- Added global and nested scopes, symbol lookup, duplicate detection, and definitions for variables, structs, functions, and function arguments.
- Added `SemanticError` and the structure for second-pass type checking.
- Improved the CLI and packaging with an installed `teapot` console script and version/help/trace options.
- Added semantic-analysis and parser regression tests.
- Improved CI and developer tooling.
