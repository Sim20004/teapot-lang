# Security Policy

## Supported versions

TeapotLang is currently in alpha. Only the latest development state on `main` and the latest published alpha release are considered supported.

Because the project is experimental, security fixes may require changes to language or compiler behaviour.

## Reporting a vulnerability

Please do not disclose a suspected security vulnerability publicly in an issue before maintainers have had an opportunity to investigate it.

If GitHub private vulnerability reporting is enabled for this repository, use it to report the vulnerability. Otherwise, contact the maintainer privately through GitHub and include enough information to reproduce the issue, including the affected TeapotLang version, operating system, Python version, relevant source code, and error output.

Please allow maintainers reasonable time to investigate and prepare a fix before publicly disclosing the issue.
