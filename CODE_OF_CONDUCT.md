# Code of Conduct

## Our standard

TeapotLang is an open-source project and welcomes contributions from people with different backgrounds and levels of experience.

Participants are expected to:

- Be respectful and constructive.
- Give feedback about ideas and code rather than people.
- Welcome good-faith questions and contributions.
- Avoid harassment, discrimination, personal attacks, and disruptive behaviour.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, pull requests, or other contributions that violate this Code of Conduct. They may also temporarily or permanently restrict participation when necessary to maintain a welcoming project environment.

## Reporting

If you experience or witness unacceptable behaviour, contact the project maintainers through the contact method documented in `MAINTAINERS.md` or through a private GitHub report when appropriate.

This Code of Conduct applies to project spaces and interactions where someone is representing or participating in the TeapotLang project.
